# IEEE InnovateX 2026 - Event Website

A responsive single-page website for **IEEE InnovateX 2026**, organised by the IEEE Student Branch with the IAS and RAS chapters at MITS Gwalior.

## Live Demo

https://prashant-7-8-7.github.io/innovatex-2026/

## Features

- Sticky glass navbar with IEEE, IAS and RAS logos and a mobile menu
- Hero section with Register Now button and live countdown
- Animated stat counters
- Event schedule timeline (3 sessions)
- 2 keynote speaker cards
- Footer with the provided footer image
- Fully responsive layout (360px to 1440px+)
- Scroll animations that respect reduced-motion settings

## Tech Stack

Plain HTML, CSS and vanilla JavaScript. No frameworks and no build step.

## Run Locally

    git clone https://github.com/prashant-7-8-7/innovatex-2026.git
    cd innovatex-2026
    npx serve .

Then open the address shown in the terminal.

## Deployment

Deployed with GitHub Pages (branch: main, folder: root).
